**Egyptian Car Plate System 🇪🇬**
A simple yet effective Python project to simulate the Egyptian Vehicle Registration System. This project was created to practice Object-Oriented Programming (OOP) and Database Management.

**Features**
Plate Generation: Automatically generates license plates with Arabic letters and numbers based on the specific letter assigned to each Egyptian governorate (e.g., 'ق' for Cairo, 'س' for Alexandria).

Vehicle & Owner Registry: Collects detailed information including owner's name, ID, car brand, and model.

Data Persistence: Uses SQLite to save all registered vehicle information into a local database file (cars.db).

User-Friendly CLI: A simple command-line interface to guide users through the registration process.

🛠️**Tech Stack**
Python: Core logic and OOP.

SQLite3: For data storage.

Random: For generating unique plate combinations.
